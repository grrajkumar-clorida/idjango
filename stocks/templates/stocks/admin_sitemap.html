REST API Endpoints

Base URL: /stocks/api/trading/

See API_DOCUMENTATION.md for complete API documentation

  • GET /strategies/ - List all strategies
  • GET /strategies/<id>/status/ - Get strategy status
  • POST /strategies/<id>/enable/ - Enable strategy
  • POST /strategies/<id>/disable/ - Disable strategy
  • GET /positions/ - List all positions
  • GET /positions/<id>/ - Get position details
  • GET /performance/ - Get overall performance
  • GET /risk/exposure/ - Get current exposure
  • GET /status/ - Get system status
